Objective: To design and implement a Python program that retrieves web pages using the requests library, parses their HTML content using BeautifulSoup, extracts product information (title, price, rating, and availability), handles multiple pages, and saves the extracted data to a CSV file for further analysis.
Target Website: The program shall use Books to Scrape (https://books.toscrape.com), a website created specifically for practising web scraping. It lists 1,000 books across 50 pages, each with a title, price, star rating, and availability status, which makes it ideal for this exercise without any legal or ethical concerns.
